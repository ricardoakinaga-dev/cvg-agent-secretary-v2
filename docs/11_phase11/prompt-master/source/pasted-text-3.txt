# CONTINUAÇÃO — PHASE 11.13

## REAL INTEGRATION READINESS

> Continuação direta do item 137. Todos os requisitos anteriores permanecem obrigatórios.

---

# 137. PHASE 11.13 — REAL INTEGRATION READINESS

A Phase 11.13 deve provar que o runtime está preparado para operar com integrações reais sem permitir que providers externos atravessem os boundaries arquiteturais.

Integrações prioritárias:

```text
EvolutionAPI
Chatwoot
Model Provider real
External Identity Provider
CVG internal systems
```

A ausência de credenciais ou infraestrutura externa NÃO deve ser contornada com mocks para obter certificação externa.

Mocks e fixtures podem provar contratos.

Somente endpoints reais podem produzir:

```text
VALIDATED_REAL
```

---

# 138. PRINCÍPIO DE INTEGRAÇÃO

Nenhuma integração externa pode ser chamada diretamente pelo:

```text
Agent
Planner
Replanner
Orchestrator
Evaluator
```

Fluxo obrigatório:

```text
Orchestrator
     ↓
Govern
     ↓
Tool / Channel / Model Gateway
     ↓
Adapter
     ↓
External Provider
```

---

# 139. ADAPTER BOUNDARY

Cada provider deve possuir adapter explícito.

Exemplo:

```text
ChannelGateway
├── EvolutionApiAdapter
├── ChatwootAdapter
└── ControlledChannelAdapter

ModelGateway
├── OpenAICompatibleAdapter
├── OllamaAdapter
├── ControlledModelAdapter
└── future providers
```

---

# 140. PROVIDER SDK ISOLATION

SDKs ou detalhes HTTP específicos de providers devem existir somente na camada apropriada.

Crie architectural tests impedindo imports proibidos.

Exemplo:

```text
packages/orchestrator
    MUST NOT import
EvolutionAPI implementation
Chatwoot implementation
OpenAI SDK
PostgreSQL implementation
```

---

# 155. CHATWOOT HUMAN TAKEOVER

Esse é um gate crítico.


# 156. TAKEOVER RACE
