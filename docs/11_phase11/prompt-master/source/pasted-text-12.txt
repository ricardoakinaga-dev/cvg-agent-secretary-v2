# 1079. MASTER SUCCESS CRITERION

O sistema final deve conseguir responder mecanicamente:

```text
What was observed?
What goal was created?
What plan was selected?
What policy governed it?
What risk was assigned?
What approval existed?
What action was executed?
What actually happened?
Was the goal achieved?
Why was it considered achieved?
Was replanning required?
Which model/agent/tool versions participated?
Which tenant owned the execution?
Which operator authorized it?
Which evidence proves each statement?
```

Se essas perguntas não puderem ser respondidas de maneira auditável para uma execução crítica, a arquitetura ainda não está completa.
