- CVG-HIS.

## Validacoes

- Timeout configurado.
- Retry idempotente.
- Fallback ou handoff.
- Erro normalizado.
- Integration event persistido.
- Dados externos nao corrompem dominio.

## Falhas esperadas

- Webhook duplicado.
- Rate limit.
- Adapter indisponivel.
- Resposta invalida.
- Permissao negada.
