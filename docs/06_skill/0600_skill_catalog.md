# 0600 — Skill Catalog CVG

## Objetivo

Este catalogo documenta as skills operacionais que devem existir para conduzir o pipeline CVG da Esmeralda V2.

## Skills

- `discovery-engine`: transforma ideia, dor ou oportunidade em problema estruturado.
- `prd-engine`: transforma discovery aprovado em produto.
- `spec-engine`: transforma PRD aprovado em engenharia.
- `build-engine`: executa construcao faseada a partir de SPEC aprovada.
- `audit-engine`: audita sistema funcional em ambiente real ou controlado.
- `runtime-controller`: mantem estado, log, backlog e continuidade.
